# ontol-edu

Тренажёр по дискретной математике, построенный на онтологии ONTOL.

База курса (понятия, определения, теоремы, задачи) представлена не таблицами, а
**онтологией** — диаграммой классов ONTOL, совместимой с UML. Записи базы суть
экземпляры классов онтологии, связанные с ними зависимостью `instanceOf`.

Главное свойство: **ответ студента проверяется запросом к онтологии**, а не
сравнением с захардкоженным эталоном. Эталон вычисляется из базы в момент
проверки и потому не может с ней разойтись. Задания «нарисуй диаграмму»
проверяются так же: SVG студента разбирается обратно в модель, и к ней
применяется тот же запрос.

## Структура

| Каталог          | Назначение                                                                                                                               |
| ----------------------- | -------------------------------------------------------------------------------------------------------------------------------------------------- |
| `ontol_core/uml_dsl/` | ядро ONTOL: модель UML, TDL ↔ SVG, рендер через Graphviz. Чужой апстрим, **только читается** |
| `ontol/query/`        | запросы к диаграмме как к помеченному графу: RPQ с узловыми атомами, CFPQ                     |
| `ontol/instances/`    | объявление экземпляров классов онтологии                                                                      |
| `discrete/`           | прикладной слой: схема онтологии, загрузчик контента, журнал попыток                     |
| `content/`            | наполнение курса в TDL --- источник истины, правится преподавателями                          |
| `docs/`               | ТЗ и принятые решения                                                                                                            |

Зависимость строго в одну сторону: `discrete` → `ontol` → `uml_dsl`.

## Запуск

```bash
pip install -r requirements.txt
python -m pytest tests -q          # на Windows полезно set PYTHONUTF8=1
```

Графика требует Graphviz в системе (`dot`).

## Пример

```python
from discrete import Profile, build_schema, reference_class
from ontol.query import diagram_to_graph, rpq_reachable

diagram = build_schema(Profile.FULL)
graph = diagram_to_graph(diagram, role_labels=True)

rpq_reachable(graph, "Теорема", "gen+")        # {'Утверждение', 'ЕдиницаКонтента'}
rpq_reachable(graph, "Задача", "проверяет")    # {'ЕдиницаКонтента'}
reference_class(Profile.FULL)                  # 'ЕдиницаКонтента'
```

Имена элементов онтологии — на кириллице (это данные, они попадают в TDL и в
текст запроса), идентификаторы Python — на латинице. Все имена собраны в
[discrete/names.py](discrete/names.py); литералов по коду нет, поэтому перевод
онтологии на латиницу сводится к правке одного словаря.

загрузчик контента с валидацией инвариантов, журнал попыток на SQLite,
генераторы вариантов задач, проверка ответов с диагностикой ошибок и
